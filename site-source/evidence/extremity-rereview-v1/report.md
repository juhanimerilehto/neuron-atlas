# What we found in Qwen3-1.7B

The numerical screen covered 172,032 MLP coordinates. In the final sweep, 2,240 shortlisted coordinates received full generations at several settings. The public explorer features eight standouts and publishes the complete catalogue of 236 findings across Qwen3-1.7B and SmolLM2-135M-Instruct. It also publishes an index with one assessed setting per shortlisted Qwen coordinate.

The featured cases illustrate language switching, paperwork, assault reframing, digit loops and topic substitution. Open the selected paired examples to compare each intervention against the same ordinary prompt. Some outputs contain violent language. Match counts and quality flags summarize the full phase at that setting. The audit checked 129,600 paired generations and 30,100 condition assessments. Terra scored change and coherence using saved outputs. Sol independently assessed 50 nominated settings. Claims are specific to the pinned checkpoint and tested prompts.

The [audit record](audit.json) describes the checks. The [campaign manifest](../exhaust-qwen-v1/manifest.json) records the underlying model and experiment provenance. See [the source repository](https://github.com/juhanimerilehto/neuron-atlas) for the workers and campaign documentation.
