# Neuron Atlas public evidence snapshot

This release selects eight coordinates from the Qwen3-1.7B retrospective audit. The explorer shows selected exact baseline, clamped and matched-control generations. Match counts and quality flags summarize the full phase at that setting. The underlying audit checked 129,600 paired generations, 2,240 coordinates and 30,100 condition assessments. Terra ran the primary retrospective review. Sol independently assessed 50 nominated settings.

The selected cases illustrate language switching, paperwork, assault reframing, digit loops and topic substitution. Open the paired examples to compare each intervention against the same ordinary prompt. Some outputs contain violent language. Validation, previously held-out cases and exploratory discovery are labeled separately. This review used saved generations and the claims remain specific to the pinned checkpoint and tested prompts.

The [audit record](audit.json) describes the checks. The [campaign manifest](../exhaust-qwen-v1/manifest.json) records the underlying model and experiment provenance. See [the source repository](https://github.com/juhanimerilehto/neuron-atlas) for the workers and campaign documentation.
